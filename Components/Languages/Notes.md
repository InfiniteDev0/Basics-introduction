1️⃣ Compilers 
            Translate entire program from High level laguage to machine language , before the program runs , so the program runs inform of a (.exe) file which is in binary code.
            
            languages : 
                        C , C++ , Rust , GO , Swift , Kotlin
            Advantages: 
                       Very fast execution 
                       Optimised performance
                       Errors Cuaght Early 
            Disadvantages:
                       Slower to test 
                       Harder to debug
                       Code is big and is run all at once

2️⃣ Interpreters
            Read Code Line By Line and excutes it as it goes 
            languages : 
                       Phyton , JS , Ruby , PHP , BASH
            Advantages: 
                       Easier to test & debug 
                       Great for beginners
                       Instant feedback
            Disadvantages:
                       Slower than compiled languages
                       Errors may appear during running

1️⃣ VMs vitual Machines
            Compiles languages into bytecode (not machine code), the bytecode runs inside a virtual machine (JVM , NET , CLR). now that machine converts the bytecode into machine code.
            languages : 
                       Java , Kotlin , C# , SCALA
            Advantages: 
                       Run anywhere
                       Safer more secure
                       Automatic memory managment
            Disadvantages:
                       Slightly slower than pure compiled languages
                       Require a Vm to be installed in the pc to run

1️⃣ Transpilers
            Takes Code in one language and coverts it into another highlevel language (often js)
            
            languages : 
                        TypeScript
                        Jsx
                        Coffeescript
            Why : because in modern web apps that use TS or JSX and made yet the browser only understands JS
